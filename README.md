## Validação
Testes em desktop e mobile 320px/390px: sem erros JavaScript ou rolagem horizontal; imagens carregadas; links conferidos; relógio atualiza a cada segundo; carrossel tem avanço automático, navegação manual e pausa. Movimento reduzido respeitado.
